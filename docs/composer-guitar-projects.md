# Moving chords between Composer and Chord Builder

The interchange file is ordinary `crest-chord-builder` project JSON. Composer reads versions 1, 2 and 3 and writes version 3. Use the JSON in Chord Builder or paste it into **Project JSON** in Chord Reference. Keep a copy of the original project if you plan to edit it again: this transfers chords, not complete sessions.

## Builder → Composer

- Parts and chords stay in file order. Select **one part** for the active sketch. A Builder part can contain 64 chords; a Composer sketch can contain eight slots. A part longer than eight must be split in Builder before loading. A long part does not prevent choosing a shorter sibling.
- A saved grip uses the guitar selected by that part. For example, standard tuning with capo 2 looks up `42,47,52,57,61,66`. Each non-muted relative fret is added to the corresponding pitch in that key, **without adding the capo a second time**. Re-entrant tunings work; doubled MIDI pitches survive; the result is sorted low to high. A grip from an old tuning, an all-muted grip or one excluded by the current hand position/open-string filters does not sound in Builder and is not imported as the voicing.
- **No usable grip:** Composer uses Builder’s chord-editor preview, not a guess at the last grip. Start at MIDI `48 + chord.root`, add each interval, and raise 9ths, 11ths and 13ths one octave. Use explicit formula spelling where present and Builder’s interval inference otherwise. If the chord specifies a bass, add `36 + bass` below the chord. An omitted root stays omitted. The result may differ from the automatic grip Builder finds later.
- The part key and harmonic root are pitch classes (C = 0). Absolute octaves come from the grip or preview. Labels are kept; an unlabeled chord gets a basic chord name, or its root and semitone intervals for a less common quality. The bridge recognizes Builder’s actual scale IDs, including `minor` (natural minor) and `harmonic` (harmonic minor). It reports `custom` as a marker; the native model cannot carry the custom definition. Only load keys/modes the sketch supports without substituting a different scale.

## Composer → Builder / Reference

- Each sketch becomes one named part on a standard six-string guitar without capo. The harmonic root is retained even in rootless voicings. Sounding pitch classes define the intervals and the lowest MIDI note defines the bass.
- If the **exact MIDI pitches** fit, the export saves a grip on `40,45,50,55,59,64` (E2 A2 D3 G3 B3 E4). It searches positions through fret 24, allows open strings, and uses a four-fret window with up to four fingers or a simple barre. This is not a complete ergonomic solver. If it cannot assign *every* note including doublings, `fingerings` is `{}`. Builder can search for a new voicing; Reference displays the harmony but cannot show a diagram until a grip is saved. Octaves and doublings cannot be recovered from intervals alone.
- **Rests cannot be exported.** Remove them from a copy of the sketch to transfer just the chords. Neither rests nor excess chords are dropped silently. An empty part (zero chords) is legal; a chord with zero notes is not. Custom scales cannot be exported without their definition.
- The format does not transfer Composer slot lengths, rests, tempo, meter, performance patterns or imported MIDI. In the other direction the bridge does not retain project title/IDs, custom sheets/attachments, alternate tuning snapshots, string assignments, the original spelling/formula, or unsounded chord tones. It reads musical data only; it never renders or executes attached content. Use native session state or MIDI for timing, and the original guitar project for sheets and tuning history.
